# Phase 2 다중 인물 대상 선택

2026-10-03 사용자가 다른 사람이 감지되어 클라이머를 선택하지 못하는 문제를 확인했습니다. 분석 후보는 여러 명, 추적과 Phase 3 크롭 대상은 선택한 한 명으로 구분합니다.

## 사용 방법

1. MediaPipe Full 또는 Lite로 전체 분석합니다. 감지한 후보는 화면과 버튼에 사람 번호를 표시합니다.
2. 영상 바로 아래의 사람 번호나 영상 위 몸 영역을 누릅니다. 선택한 번호의 관절만 초록색으로 표시하고 나머지 후보의 번호도 유지합니다.
3. 원하는 사람이 없으면 사람 번호 오른쪽의 사람 추가 아이콘(`놓친 사람 영역 추가 분석`)을 누릅니다. 영상 위에서 드래그하여 다른 사람은 제외하고 클라이머의 몸과 이동 경로를 포함하는 영역을 지정합니다.
4. `이 영역 추가 분석`으로 같은 모델과 샘플 시간에 추가 분석합니다. 새 후보를 기존 후보와 합친 뒤 원하는 사람 번호를 다시 선택합니다. 모델 자체를 바꾸려면 전체 재분석을 사용합니다.
5. 결과를 저장하면 schemaVersion 2 JSON에 selectedPersonId, 프레임별 personIds와 원본/보정 대상 관절, 분석 영역을 기록합니다. Phase 3는 이 선택 결과를 크롭 경로의 입력으로 사용할 수 있습니다.

ML Kit Accurate는 한 입력에서 한 사람만 반환하므로 화면 전체에서 사람 둘을 자동으로 모두 감지하지 않습니다. 추가 영역 분석은 해당 사람에 집중할 수 있도록 입력 영역을 좁히는 방법입니다. [ML Kit 공식 제한](https://developers.google.com/ml-kit/vision/pose-detection), [MediaPipe 최대 인물 수 설정](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker).

## 화면 배치

영상·사람 선택·재생 및 시간 이동을 하나의 상단 패널에 묶었습니다. 모델 설정, 관절 보정, 저장과 결과 정보는 아래 영역에서 따로 스크롤합니다. 설정을 아래로 내려도 영상을 보며 사람을 바꿀 수 있습니다. 선택한 번호에는 체크 표시와 강조색을 표시하고, 후보가 많으면 번호 줄을 가로로 넘깁니다. 모델 반환 순서가 바뀌어도 버튼은 사람 번호순으로 유지합니다.

화면 높이에 맞춰 영상 높이를 조절합니다. 가로 폭이 넓은 화면은 영상과 조작 패널을 왼쪽, 설정을 오른쪽에 나란히 표시합니다. 아주 낮은 화면이나 큰 글씨로 패널이 넘치면 영상 패널 안에서도 스크롤할 수 있습니다. 영역 드래그의 확인·취소도 영상 옆 조작 영역에 표시합니다.

## 정확도와 한계

- 번호는 위치·크기·이동 방향으로 연결합니다. 모델이 반환한 순서가 바뀌어도 번호를 유지합니다.
- 겹침에서 연결이 애매하면 `구분 중`으로 표시하고 선택을 막습니다. 2초 이상 끊기면 새 번호가 생길 수 있습니다. 같은 사람이 영상 전체에서 항상 같은 번호를 갖는다는 보장은 없습니다.
- 선택한 번호가 사라졌다고 다른 번호의 사람으로 자동 전환하지 않습니다. 분명한 시점에서 다시 선택할 수 있습니다. 여러 수동 구간을 이어 붙이는 편집은 후속입니다.
- 추가 영역은 영상 전체에서 고정입니다. 영역 밖으로 이동하거나 사람 둘이 동시에 영역에 들어오면 놓칠 수 있습니다. ROI 입력은 이미지 분석 모드를 사용해 이전 대상 기억이 다른 위치에 영향을 주는 것을 줄입니다.
- 추가 분석 취소·실패 시 이전 결과와 선택을 보존합니다. 성공하면 다시 대상을 선택합니다. 중복 감지한 사람은 후보를 추가하지 않습니다.
- 원본을 재인코딩하지 않습니다. 내부에서 작은 프레임과 분석 영역을 사용하며 표시 좌표는 원본 전체 화면 기준으로 복원합니다. 실제 크롭·인코딩·영상 내보내기는 Phase 3 이후 범위입니다.

## 검증

공통 테스트는 반환 순서 변경, 두 사람 겹침과 재분리, 짧은 누락과 긴 가림, 영역 결과 합치기와 중복 제거, 사람 2 선택·저장, 영역 분석 취소·실패 시 보존, 실제 드래그 화면 흐름을 검증합니다. Android 모델 실행 결과는 Android 검증 기록, iOS 실행 제한은 iOS 검증 기록에 따로 기록합니다.

UI 재배치 후 화면 테스트와 정적 분석을 통과했습니다. 390×844, 390×600, 844×390 화면에서 영상·사람 선택·재생/탐색이 함께 보이고, 설정 스크롤 뒤에도 영상 위치가 유지되는지 확인했습니다. Android 에뮬레이터의 실제 영상에서도 결과 저장 영역까지 스크롤한 채 사람 2→사람 1을 눌러 대상 변경과 영상 위치 유지를 확인했습니다. 캡처는 build/phase2-screenshots/phase2-subject-controls.png이며 개인 영상과 함께 Git에는 포함하지 않습니다.
