# Phase 2 — 관절 분석과 단일 대상 추적

## 브랜치

Phase 1 기준은 `aedcc0c`입니다. 사용자가 재생·탐색, 반복 영상 교체, 사진 전환, 선택 취소·백그라운드 정지, 크기·해상도 표시의 수동 검증 5개를 모두 통과했다고 확인했습니다.

- `phase2-analysis`: 공통 Flutter 코드 + Android 구현.
- `phase2-ios`: 같은 공통 커밋 + iOS 구현. Android 전용 변경은 포함하지 않습니다.
- 공통 수정은 양쪽에 반영해야 합니다. 브랜치의 OS 부분을 합칠 때 공통 기준 커밋 이후 변경을 검토합니다.
- 원격 푸시는 별도 요청 시 수행합니다.

## 기능과 한계

미디어 화면 → 분석 화면 → 모델·간격 선택 → 분석 → 클라이머 선택 → 관절/추적 결과 확인 → 앱 내부 JSON 저장.

사람 선택은 자동 대상 전환의 위험을 줄이기 위한 한 번의 확인입니다. 분석 후 영상의 원하는 시점에서 후보 번호나 사람 영역을 누릅니다. 선택 시점의 앞뒤를 추적합니다. 원래 관절 좌표와 보정한 좌표를 비교할 수 있습니다.

MediaPipe Full/Lite를 공통 후보로 사용합니다. Android는 ML Kit Accurate도 지원합니다. 여러 모델을 같은 파일·간격으로 실행하면 감지 프레임 수, 평균 모델 실행 시간, 전체 분석 시간을 비교할 수 있습니다. 이 수치는 관절 위치의 실제 정확도나 대상 전환 횟수를 대신하지 않습니다. 클라이밍 영상에 대한 최종 모델 선정은 수동 확인을 포함한 비교 이후입니다.

기본 분석은 초당 5프레임, 선택 가능 값은 2/5/10입니다. 최대 10분·6,000프레임으로 제한합니다. 영상 전체나 모든 프레임 이미지를 메모리에 쌓지 않습니다. 원본은 읽기만 하고 결과에는 회전 적용 후 이미지 기준 0~1 좌표를 사용합니다. 저장 영상의 프레임 간 관절 표시는 가장 가까운 분석 시점의 결과이므로 빠른 동작에서 약간의 오차가 있을 수 있습니다.

대상 연결은 몸통 중심·몸 크기·이동 방향을 사용합니다. 여러 후보가 비슷하면 인물 번호 연결을 보류합니다. 선택한 번호가 없으면 `lost`로 기록하며, 번호 없는 기존 결과의 대상 연결은 서로 비슷한 후보를 `ambiguous`로 기록합니다. 번호가 없는 좌표만의 추적은 2초 이상 놓친 뒤 연결을 중단합니다. 현재 번호가 연결된 대상은 동일 인물 기록이 다시 확인되면 추적을 이어갑니다. 얼굴/복장 기반 인물 식별 모델은 아니므로 교차나 심한 가림에서 동일 인물임을 완전히 보장하지 못합니다. 재선택은 해당 시점을 기준으로 전체 추적을 다시 계산하며 여러 수동 구간을 이어 붙이는 편집 기능은 후속 범위입니다.

관절 보정은 신뢰도가 낮은 지점을 숨기고 동작 속도에 따라 평활화 강도를 조절합니다. 영상 픽셀을 재인코딩하는 보정이 아닙니다. 사람 영역 마스크를 이용한 배경 제거와 영상 인코딩·내보내기는 후속 범위입니다. 크롭 미리보기·경로 저장은 Phase 3에서 구현했습니다. 포즈 후보 인식으로 사람 위치와 배경을 구분하며 정밀한 픽셀 분리는 별도 기능입니다.

## 공통 구조

- `features/analysis`: 화면, 분석 상태, 33개 관절·후보·대상 모델.
- `core/pose`: OS 연결 서비스, 원자적 JSON 저장.
- `core/tracking`: 다중 후보 번호 연결, 단일 대상 연결과 관절 평활화.
- `assets/models`: 양쪽에서 함께 쓰는 공식 모델 번들.

화면 종료와 취소 시 세션을 닫습니다. 백그라운드 진입 시 영상은 정지하고 분석은 취소합니다. 늦게 도착한 결과는 버립니다. 원본 영상 프레임은 네이티브에서 추출·분석한 뒤 바로 해제합니다.

## 플랫폼 연결 계약

채널: `crux_cam/pose`. 메서드는 메인 스레드에서 수신하고 실제 작업은 직렬 작업 큐에서 실행합니다. 각 분석에 Dart가 고유 `id`를 부여합니다.

| 메서드 | 입력 | 결과 |
|---|---|---|
| engines | 없음 | 지원 모델 ID 목록 |
| open | id, path, type(image/video), engine, 선택적 region([left,top,right,bottom]) | width, height, durationMs, storageDirectory |
| frame | id, timeMs, preview | timeMs, poses, inferenceMs, 선택적 JPEG preview, 사람별 선택적 appearances |
| close | id | 취소 신호 전달 및 세션 해제 완료 |

`poses`: 사람별 33개 `[x, y, z, confidence]` 배열. MediaPipe의 confidence는 visibility/presence 중 낮은 값, ML Kit는 inFrameLikelihood입니다. 두 점수의 정의가 다르므로 같은 숫자를 정확도처럼 직접 비교하지 않습니다. z는 3D 실측값으로 해석하지 않습니다. 비어 있는 poses는 인식 실패이며 통신 오류와 구분합니다.

이미지/영상 회전은 네이티브에서 적용하고 그 크기로 좌표를 반환합니다. 시간은 요청한 샘플 시점(ms)을 뜻하며 프레임 추출 API의 근접 프레임 선택 오차는 남을 수 있습니다. 전체 화면의 MediaPipe VIDEO 모드에는 증가하는 샘플 시간을 전달합니다. 추가 영역 분석은 입력 영역 변화로 모델 내부의 대상 기억이 섞이지 않도록 IMAGE 모드를 사용합니다. 영역 좌표를 원본 전체 화면 좌표로 복원하고 preview와 width/height는 전체 화면 크기를 유지합니다.

저장: 앱 전용 영구 디렉터리 `analysis/pose_<시간>.json`, schemaVersion 2. 후보·원시 대상·보정 대상·상태·모델·간격·실행 시간·선택 기준 시점을 보존합니다. 임시 원본 파일의 영구 보관이나 앱 재실행 후 결과 목록·불러오기는 아직 제공하지 않습니다. 분석 결과 저장은 갤러리 영상 내보내기가 아닙니다.

## 완료 검증

자동 검증: 사람 순서 변경, 다른 사람 배제, 교차 시 보류, 긴 가림, 중간 시점 선택, 좌표 보정, 분석 취소·실패·해제, JSON 저장. Android는 실제 디코더/모델 통합 테스트와 APK 빌드로 확인합니다.

사용자 영상에서는 등진 자세, 홀드와 몸에 가려진 팔다리, 다른 사람 진입, 세로 회전, 빠른 이동·낙하를 확인합니다. 에뮬레이터 속도는 실기기 성능을 대표하지 않습니다. iOS 소스 작성과 실행 검증 상태는 별도로 기록하며, Mac/Xcode/iPhone에서 빌드·자원 해제·좌표 정합 검증이 필요합니다.

## 여러 사람이 보이는 영상 (2026-10-03 보완)

감지 후보는 여러 명을 허용하되 크롭할 대상은 한 명만 선택합니다. 사람 번호는 모델 배열 순서 대신 프레임 사이 위치·크기·이동 방향과 옷 색을 함께 보고 연결합니다. 선택한 번호의 후보만 대상 추적에 사용하고, 선택 후에도 모든 후보의 번호와 영역을 표시합니다.

ML Kit는 입력 한 장에서 한 사람만 반환합니다. MediaPipe는 최대 4명 설정이지만 작은 사람이나 가려진 몸을 항상 찾지는 못합니다. 놓친 사람은 사용자 지정 영역을 영상 전체에서 추가 분석하여 기존 후보와 합칠 수 있습니다. 번호 중복은 몸통 위치와 영역 겹침으로 제거하고 기존 번호를 보존합니다. 저장 JSON에는 프레임별 personIds, selectedPersonId, analysisRegions를 추가했습니다.

이 번호는 얼굴·복장으로 식별한 영구 인물 ID가 아닙니다. 비슷한 위치에서 겹치면 번호를 보류하고 잠깐 놓쳤다고 기록을 지우지 않고 기존 번호를 다시 연결합니다. 지정 영역은 고정되어 있으므로 클라이머의 이동 경로를 포함해야 합니다. 추가 분석 취소·실패는 이전 선택을 보존하고 성공 시 후보를 갱신해 대상을 다시 선택합니다. 사용 절차와 검증은 [다중 인물 대상 선택](PHASE2_SUBJECT_SELECTION.md)에 있습니다.

2026-10-06 보완: 번호 기록은 분석 전체에서 유지하고 추가 영역은 별도 새 번호 그룹으로 처리합니다. appearances는 사람별 96개 몸통 HSV 색 분포이며 optional입니다. 얼굴·개인 식별 정보는 포함하지 않습니다. 크롭 미리보기·경로 저장은 PHASE3_CROP.md에 정의합니다.
