# Phase 3 크롭 미리보기

## 현재 범위

분석 화면에서 사람을 선택한 뒤 `크롭 미리보기`를 엽니다. 선택한 사람의 보정 좌표를 사용해 크롭 영역을 계산하고 실제 영상을 해당 영역으로 표시합니다.

- 원본 비율, 9:16, 16:9, 4:5, 3:4, 1:1.
- 확대 정도 1.0~2.5. 기본값은 관절 범위에 여유를 두며 큰 값일수록 가까이 표시합니다.
- 부드럽게 따라가기 설정. 빠른 움직임은 더 빨리 따라가고 축소는 확대보다 빠르게 적용합니다.
- 크롭 화면과 원본 위 크롭 영역 표시를 전환합니다. 재생·일시정지·시간 이동과 백그라운드 정지를 지원합니다.
- 대상을 놓친 구간은 마지막 위치를 유지합니다. 최초 감지 전에는 선택 비율에서 가능한 넓은 영역을 표시합니다. 다른 번호의 사람을 따라가지 않습니다.
- 크롭 경로와 설정을 앱 내부 JSON에 저장합니다. 원본은 변경하지 않으며 영상 파일 내보내기는 후속 인코딩 단계입니다.

## 계산과 데이터

`CropPlanner`는 선택된 프레임별 대상 관절의 범위에 여유를 두고 출력 비율에 맞춘 영역을 만듭니다. x와 y가 모두 0~1이어도 픽셀 비율은 원본 가로/세로 크기에 따라 다르므로 출력 비율과 원본 비율을 함께 사용합니다. 모든 영역은 영상 경계 안으로 제한합니다.

연속 추적 구간의 샘플 사이에는 위치와 크기를 선형 보간합니다. 인식이 끊긴 구간을 미래의 위치로 미리 이동시키지 않습니다. 미리보기는 원본 플레이어의 표시 위치와 크기를 바꾸므로 중간 영상을 재인코딩하지 않습니다. 넓은 비율이나 큰 확대에서 전신이 한 화면에 들어가지 않으면 일부 관절이 잘릴 수 있어 화면에 안내합니다.

저장 파일: 기존 분석 저장 디렉터리의 `crop_<시간>.json`. schemaVersion 1, kind=crop_timeline, sourceName, 원본 분석 좌표 크기, durationMs, personId, engine, ratio/zoom/smooth와 프레임별 timeMs/rect/status를 포함합니다. rect는 `[left, top, width, height]`이며 회전 적용 후 원본 전체 화면 기준입니다. 영상 렌더링 단계는 원본 실제 픽셀 해상도로 이를 변환해야 합니다.

JSON 변환·크롭 경로 계산은 별도 실행 공간에서 수행합니다. 설정을 빠르게 바꿔도 늦게 도착한 이전 결과는 적용하지 않습니다. 저장은 임시 파일에 완료 후 이름을 바꾸고, 화면 종료 시 재생기·타이머를 해제합니다.

## 후속 범위

원본 영상으로 MP4를 렌더링하고 코덱·출력 해상도·음성을 선택해 갤러리로 내보내는 작업, 결과 불러오기와 원본 영구 보관, 여러 재선택 구간을 이어 붙이는 편집은 아직 구현하지 않았습니다. 현재 사진은 크롭 미리보기·설정 저장만 지원합니다.

## 2026-10-06 검증

정적 분석과 공통 자동 테스트 48개를 통과했습니다. 모든 비율·원본 방향의 경계 제한, 보간 비율 유지, 확대·평활화, 누락 구간 유지, 모델 설명 전환, 크롭 화면 진입·비율 변경·JSON 내용·재생기 해제를 확인했습니다.

Android API 36 에뮬레이터의 실제 클라이밍 영상에서 사람을 선택하고 크롭을 미리봤습니다. 크롭 설정 JSON 저장과 12초 구간의 실제 재생·시간 이동, 분석 화면 복귀를 확인했습니다. 캡처는 build/phase2-screenshots/phase3-crop-preview.png와 phase3-crop-motion.png이며 개인 영상·좌표 보고서는 Git에 포함하지 않습니다. iOS는 같은 공통 코드를 반영하며 실제 빌드·실행은 Mac에서 확인해야 합니다.
